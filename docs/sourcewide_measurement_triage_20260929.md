# What the proposed source actually demands of measurement

A pinned, data-only scan of all1,140 BigCodeBench v0.1.4 source rows found **715** declaring native numerical/data/plot libraries, **341** declaring plotting libraries, **67** network-related libraries, **11** web frameworks, **313** with static randomness markers and **295** with reference file-I/O markers. Categories overlap. Among the341 plotting-library rows,236 lack the specific direct plot-data assertion markers searched by this script; that does **not** prove their tests ignore plotted values, because other test logic may inspect them. The counts are deterministic source-text/library flags, not runnability, dependency closure, semantic correctness, eligibility or independent family counts. Full row flags and source/hash binding are in results/bigcodebench_measurement_triage_20260929.json; script scripts/triage_bigcodebench_measurement_v1.py reads only pinned parquet data, with no task or model execution.

This changes a concrete design priority: the existing literal JSON observer is insufficient for a source-wide policy trial. A proposed native-test-score endpoint would need a contained execution and trusted observation path for arrays, DataFrames, figures and side effects, plus a versioned report of where source tests do and do not constrain task behavior. Task58's wrong constant plot passing its5/5 native tests remains an actual counterexample to treating native pass as semantic plot correctness. Source review60–73 shows related chart coverage gaps. Neither a static flag nor one native smoke fixture admits a task.

The BigCodeBench proposal remains a population inquiry. All1,140 IDs stay in the review ledger, including network and dependency-heavy rows; ease of execution is not an eligibility filter. Before any independent evaluation, settle the endpoint name and source-isolated observation/case protocol, review source families and development exposure globally, then freeze a full eligible family frame and sampling law. A feasibility finding that these gates cannot be met should be reported; shifting to easier tasks or a different endpoint would be a new scientific target.
