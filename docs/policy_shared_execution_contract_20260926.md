# LEAD-MEASUREMENT-02: one shared initial draw, canonical branch reuse

Codex scientific lead, 26 September 2026. **Prospective design decision, not a complete trial freeze or execution assignment.** This fixes a coupling and replicate choice before any new PATCH/RETHINK outcomes. It preserves the supported policy-value question and reliable-receiver quality endpoint. Actual task families, source-valid endpoints, receiver/seed law, total numerical cap and lease still need to be frozen.

## Sampling and branch objects

Use **R=1 continuation per action per root** for the first development and independent evaluation stages. Each root receives one initial draw and one bounded public diagnostic attempt. The two supported whole recipes each receive one continuation from that exact saved prefix. B2-1R returns the initial artifact on all-public-pass; otherwise it receives one independently seeded bare-task draw. Do not require B2 to spend a call on public pass. This choice economizes repeated branches so the eventual budget can cover more families; it is not a proven optimal allocation or a power guarantee. One draw does not identify an individual history's treatment effect.

For each root, the planned primitive namespaces are `INITIAL`, `PATCH`, `RETHINK`, and conditional `B2_REDRAW`. Each refers to an execution identity, request bytes, receiver/decoder identity, saved raw artifact hash and frozen scoring identity. Private grading creates one score record per executed primitive and endpoint, reused without regrading within that root. A matching content hash from two separate executions does not merge their identities. A separate score version also cannot be silently merged. Execution namespaces must distinguish intended draws, but distinct labels or numeric seeds alone do not prove independence or the required conditional seed law. A future product seed law must not silently be replaced by rejection of numeric seed collisions: conditioning away collisions changes that law. The full freeze must specify actual generation probabilities and seed dependence, not just a list of different labels.

In development both recipe scores feed the frozen learner; any B2 score is descriptive only and cannot select the learner, split or gate threshold. The policy map d and fixed recipe b1 must be frozen before opening any evaluation outcome. On each evaluation history, d and b1 select the **same canonical action primitive** whenever their chosen action is the same. When they choose different actions, their respective PATCH/RETHINK primitives are different draws. B2 on public pass uses INITIAL; otherwise it uses the separately labeled B2_REDRAW, even if its raw text happens to match another output. All observed case statuses, including INCOMPLETE and mixed states, remain in the action support.

This is a predeclared paired coupling of whole policies, not a post-outcome best-branch choice. Under a stable receiver with correct prefix restoration, require the continuation and scoring distribution of each action primitive **conditional on the saved history and frozen development information** to equal that action's deployed-policy law. The initial/diagnostic law must match too. Correct unconditional seed marginals alone are insufficient when d selects an action from history. Cross-action coupling can be arbitrary for mean-value identification if these conditional marginals are preserved. Sharing an action primitive changes joint covariance, not marginal policy value. Those stability/isolation/conditional-law conditions are assumptions requiring operational audits; they do not follow from slot names or passing unit tests. Dependence within a family is allowed; independent-family inference still requires its separate sampling/transition argument.

## Scores, unknown histories and STOP

Let each primitive quality be its observed binary grade or [0,1] if grading/output is unobserved under a valid latent experiment. Form root contrast coefficients before interval subtraction. If d and b1 choose the same action on a known history, +1 and -1 attach to the same canonical primitive, so that root contrast is exactly zero even if its grade is missing. If they choose different actions, missing scores do not cancel. Average root contrasts within each family using the frozen root weights, then apply the accepted equal-family inference procedure.

An absent initial history generally leaves the action choice and scores unobserved. It is not a shared primitive, and its generic contrast bounds remain [-1,1]; apply the v2 learning rule in LEAD-MEASUREMENT-01 for training. Only a separately proved equality of complete policy functions can justify an expected contrast of zero there. Expected-value equality by itself is not equality of two separately drawn realized outcomes. This design's canonical coupling can justify a sharper latent realized bound only after the complete missing-history policies and seed law are defined; do not infer it from a constant four-cell map alone.

STOP is the deliberate B2 all-public-pass decision returning INITIAL unchanged, with no additional receiver call. It is not a synonym for a lost history, service failure, cap-truncated slot, renderer rejection or integrity hold. Completed empty initial text is an observed artifact with a public format-error diagnostic in the [source probe](../results/empty_artifact_source_probe_20260926.json), not missing history. Its renderer support still needs a versioned correction before collection. No common fallback for malformed, oversized or unbound diagnostics is created by this note.

## Acquisition and deployment accounting

For a valid root, study generation uses at most **four receiver calls**: one initial, two recipe branches and one B2 redraw. On B2 public pass it uses three. This is research acquisition, not four calls charged to every deployed policy. End-to-end deployment uses initial plus one continuation for d/b1, and initial plus zero or one redraw for B2, along with the common initial diagnostic. Count all actual checker/grader starts, source-audit controls, input/output tokens, latency, energy and monetary cost separately; R=1 does not set a complete resource cap or equate costs. Extra counterfactual branches and hidden grading are study expenses, never decision inputs.

All planned roots/families and action slots remain in the manifest and denominators, including unattempted/censored ones. Freeze execution order before outcomes and never replace failed roots. No propensity weight is needed for complete inclusion of the two action branches; scheduling randomization is not treatment assignment. The actual seed/transition law still matters for what mean is estimated. This first landmark design is not yet a learned STOP policy, richer history model, prompt generator or repeated-deployment validation; those remain parts of the original scientific program.

Full-project readiness **58%, change 0 points**. No new efficacy or independent-policy credit; endpoint/family audits and the full prospective release remain outstanding. No worker assignment or model execution is authorized by this note.

Internal mathematical review accepts the coupling argument with the explicit conditional-on-history marginal-law requirement above; no receiver or operational independence validation has occurred.
