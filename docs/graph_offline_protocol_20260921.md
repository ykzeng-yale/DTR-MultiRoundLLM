# Frozen scope for offline graph measurement checks

21 September 2026. This is a **separate controlled measurement extension** of
the landmark design. It neither replaces the seven coding roots nor estimates
prompt efficacy. No receiver calls, benchmark candidate programs, sandbox changes,
package installations or model downloads are allowed in this work package.

The accompanying `experiments/landmark/graph_fixture_config_v1.json` fixes 32 root
seeds, graph-size/edge-probability schedules, a three-color domain, 128 attempts
per root, a single shared development family, a 60-second/512-MiB/10-MiB cap and
15 hand-authored triangle response controls before implementation. These fixtures
were chosen without model outcomes. Extra adversarial unit checks may be added
as implementation bugs are found; label those as audits rather than pretend they
were frozen in the initial control list.

The selected upstream functions generate ordinary Python data and verify JSON
color assignments; no supplied response is evaluated as code. Narrowly preserve
the pinned source bodies and applicable Apache-2.0 license/notices. Publish the
extraction manifest and local changes. Retain the existing landmark collector
and inference; this offline adapter does not make its old three-arm renderer into
the new five-arm experiment.

Required output is a new immutable directory containing public-only tasks,
private reference colorings, every attempted root's acceptance/failure ledger,
fixed-control outcomes and a manifest binding config, code and upstream hashes.
Record actual time, memory and artifact bytes. Cap failures remain failures; no
backfill. A generated task is eligible only under the declared greedy-success
rule. This is not a representative sample of all colorable graphs.

The strict response contract accepts one JSON object with exactly the canonical
string keys of the declared vertices and integer colors in the domain. Reject
duplicate keys, booleans, floats, extra keys, malformed or oversized produced
responses. A truly absent response remains missing, not zero. Scores are binary;
do not inherit upstream partial credit. Return only public constraint diagnostics;
the reference coloring is never a prompt or diagnostic input. A complete public
verifier makes public-pass stopping a different information regime from coding
with incomplete tests. Graph generation and reference/fixture checking validate
that narrow measurement law, not a practical need for an LLM over a graph algorithm.

Split every generated root and descendant into development only under one
conservative family label. Audit seed/root collisions and exact graph duplicates;
no topology-family independence or absence of pretraining exposure is claimed.
Future model collection still needs exact interventions, receiver/server versions,
state restoration, costs, assignment/order, useful-gain/precision rules and its
own committed freeze. Any learned-policy trial needs separate untouched roots.

Commit this config/protocol before implementation and record that commit as the
offline design freeze. The execution manifest must additionally pin the actual
implementation revision; an initial protocol commit cannot bind later code.
