## Measurement finding: a grader misclassification (both missing grades)

Both missing grades are S0 replicate 1 outputs, on mbpp/378 and mbpp/489. Each ends with a module-level
`return …` statement after self-test prints:

- **Why the format rule passes them.** Python's parser accepts that, so the declared format rule
  (`extract_code` + `ast.parse`) passes both.
- **Why they are then missing.** The compiler rejects them with `SyntaxError: 'return' outside function`
  before the harness start marker runs, and the grader records this as `grader_environment_failed_before_payload`.
- **Where the error lies.** The saved stderr places the error on the candidate's own last line.

So these are **candidate compile failures misattributed to the environment**. The public checker's static
gate shares the same blind spot.

- **As frozen:** the grades stay missing. No regrading or retry is done.
- **Sensitivity:** scoring both as 0, which a program that does not compile would certainly get, gives S0
  10/14. That equals R1 and leaves every other contrast unchanged. Recorded and sensitivity values are both
  reported.
- **Proposed prospective repair (needs review; it changes the grading contract):** the format rule should use
  `compile(code, "<candidate>", "exec")` rather than `ast.parse`, so compile-time errors are static format
  failures. It is not applied to this run.

## Interpretation (descriptive)

With public examples in the initial prompt, 6 of 7 initial answers were already correct and passed every
public example. That leaves one root where repair was possible and six where only damage was.

On that root no strategy repaired, including the diagnostic-directed instruction with identical diagnostic
bytes. S1 and N1 tie everywhere. Context removal (R1) was the only arm that damaged correct answers. The
syntactic cue (S0) produced the longest outputs and both uncompilable ones.

**Scope:** this is one realization on reused development roots. It neither supports nor refutes the
history-conditional prompt hypothesis in general. The dominant constraint is the ceiling: seven roots with
6/7 correct at STOP have almost no room for repair. A useful test needs roots with non-trivial initial failure
rates, chosen by a prospective design rather than from these outcomes. Policy validation remains separate
and unreleased.
