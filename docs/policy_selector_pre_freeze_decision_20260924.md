# LEAD-POLICY-01: status-only selector is not the policy freeze

Coordinating scientific lead, 24 September 2026. **Decision: HOLD E14 and independent-policy model collection.** This is a reused-development-data and prospective-design judgment for the original same-prefix, history-conditional next-prompt question. It is neither a fitted policy nor a new empirical trial. The E11, E12 and E13a negative results retain their reported scope.

The [saved E12 status audit](../results/e12_public_status_signal_20260923.json), SHA256 `320f6480a7468a955b08a00feaf0aa89293e6e828c773df74065984942ca179e`, was checked again against its fourteen root rows and pinned input hashes. Among nine `pass` roots, N1 and S1 each score 18/18; among five `wrong_value` roots, N1 scores 2/10 and S1 1/10. Thus the *observed development-sample* maximizer of N1 versus S1 in each of these two status cells is N1 (tie broken toward N1). A rule trained only on this two-cell status table would choose N1 for every **observed** E12 status, and its observed contrast with fixed N1 would be zero by construction. The third E14 S1 branch, for incomplete public information, has no E12 root in this audit. This does not prove no useful public-history heterogeneity: two continuation draws per arm, thin private suites, one unresolved development-family placeholder and outcome-inspected cells cannot establish conditional effect signs or population value. No E12 evaluation root can be repurposed as untouched policy validation.

This narrows the design: **do not simply relabel the public-status S1 instruction rule as the learned selector `d`** or treat its E12 performance as a validation signal. If `d` is to differ meaningfully from a fixed continuation, it needs a prospectively specified permitted-public-feature dictionary and a training/tie-breaking rule, with all private grades restricted to development families and all evaluation families untouched. Its support must be exact same-checkpoint continuation recipes under one receiver, terminal instruction and scoring law. A selector that only reproduces fixed N1 is a valid null implementation check, not evidence of adaptive benefit.

For the [two-comparator policy target](independent_prompt_policy_validation_design_20260922.md), N1 is a **candidate** `b1` because it is a fully specified continuation arm in E12; it is not yet certified as the competent fixed comparator. The `b1` development-selection rule, recipe bytes and tie-break must be fixed without evaluation labels. The practical `b2` candidate is bare-task independent resampling from the same landmark opportunity; it may ignore the prior answer but receives the same available public record and can use only its own subsequent public checks. Its exact restart prompt, check/accept/stop rule, maximum draws, handling of zero success, and total resource accounting must be frozen. E13a FRESH is a five-history development diagnostic of that package, not a validation of this `b2`. A full-prefix redraw would be a different intervention and must not be silently substituted. The primary `d` versus `b1` quality contrast remains the prompt-choice mechanism test; any practical or cost claim requires a fair, fully specified `b2` and total-deployment-cost analysis.

**Next discriminating deliverable, owned by the lead:** specify the public-feature bytes and selector-fitting rule; select/freeze `b1` on development data; write the complete `b2` algorithm and equal-opportunity budget; certify an untouched family sampling frame, endpoint and failure law; then set assignment/seed probabilities, useful-gain and simultaneous precision/futility rules, and a numerical local cap. The present 198-root mechanically screened convenience frame does not certify the original independent-family population or meet the existing conservative 0.05-radius planning target. A finite-set alternative is a changed hypothesis and requires its own label before collection. This decision does not release source renewal, E14's proposed 130 calls/228 starts, or any local run.

No new model calls, tokens, benchmark-program executions, simulated draws, fits or paid spend; read-only comparison of existing rows and contracts. **58%, change 0 percentage points** under the fixed rubric. Prompt efficacy remains unestablished; independent policy validation is absent; the full project is not submission-ready.
