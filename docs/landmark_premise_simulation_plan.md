# Frozen diagnostic plan: personalization versus noisy oracle selection

20 September 2026. This is a new synthetic diagnostic of the scientific premise, not LLM evidence. Commit this plan before running the experiment. It addresses a gap in the prior value-estimation simulations: a zero average prompt contrast does not rule out useful history-dependent selection, and choosing the best noisy branch can exaggerate attainable benefit.

Use 300 replications of each of four declared two-action conditions, 800 independent training roots and 800 independent evaluation roots per replication. Training actions are randomized uniformly. A transparent learner estimates action means separately within a binary public history X; its policy chooses the larger estimated mean. A competent fixed comparator chooses its arm using training data only. No test outcomes select policies or hyperparameters. Report their paired evaluation-root difference against its known population truth, conditional on training.

The public history X is Bernoulli(.5). Conditions are: (1) homogeneous null, both means .65; (2) qualitative interaction, action means (.8,.4) at X=0 and (.4,.8) at X=1; (3) weak interaction, (.64,.56) and (.56,.64); (4) unavailable signal, an independent unobserved root variable Z determines the (.8,.4)/(.4,.8) means, while only X is available to the policy. Marginal arm means are identical in every condition. This is a controlled premise test, not a proposal to omit observed confounders in real data.

Generate four independent evaluation draws per action conditional on the root state. Report r=1 and r=4 evaluations using nested draws; these are two analyses of the same simulated datasets, not independent replications. The independent training law and all fitting rules stay fixed. Total: 1,200 simulated train/test datasets and 2,400 paired-policy evaluations. Seed for condition c and replicate b: 2026092100 + 10000*c + b. No tuning or scenario deletion.

Report learned-policy population gain and regret, observed paired gain, approximate 95% root-Wald coverage (Monte Carlo SE), false-positive/detection frequency of lower endpoint >0, expected sample-max branch value, true public-history oracle value, and their difference. Distinguish finite-replicate max noise from the unavailable-signal condition, where root-specific latent information is also unavailable to the actual policy. Do not call either sampled oracle a deployable policy. Report all conditions even if the learner fails.

Budget: local CPU only, $0 spending, no receiver/model calls, no candidate-code execution. Intended runtime under two minutes. This script is a scientific diagnostic of a declared finite law; passing it does not complete prospective prompt-effect validation. Formal source context is established policy learning, e.g. [Athey and Wager](https://arxiv.org/abs/1702.02896); no foundational novelty is claimed.
