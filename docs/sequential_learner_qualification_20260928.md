# Prospective qualification of a non-oracle STOP learner

Codex lead,28September2026. This is a NEW synthetic implementation qualification, not additional collection on the nine reused LLM roots, an independent efficacy trial, or a new causal theorem. No benchmark/model call, installation or generated program execution is involved. The purpose is to bridge a concrete implementation gap: existing E0 STOP anchoring uses observable true quality, whereas deployment only observes a noisy public check. The new component learns STOP values from training outcomes and preserves full public histories. It is a finite-cell component, not a text encoder or the finished practical controller.

Established backward Q-learning and known-propensity longitudinal augmentation are the algorithms (see classical attribution in docs/theory.md and references.bib). Fit both full-history and last-observation conditional means on the same randomly assigned training episodes; STOP-first tie rule is fixed. Missing action cells cause STOP fallback for deployment, explicitly measured; absent next-stage STOP support fails fitting. Evaluation Q support gaps cause score refusal, not fabricated values. The compressed fit is intentionally potentially misspecified; no claim that current public status is causally sufficient. Private terminal outcomes are training labels, never policy features. No model is trained on the matched-strategy panel.

The fully specified law has latent binary correctness Q, baseline observable mode Z and a noisy public result O. Initially Z is equiprobable and Q~Bernoulli(.55); first public symbol encodes (Z,O). After a continuation the public observation is O alone, so complete history retains mode while last-observation compression loses it. Two decisions, each action STOP/PATCH/RETHINK uniformly randomized with logged full vector(1/3,1/3,1/3); STOP absorbs and reveals terminal Q only to the evaluator. In the null regime all actions preserve Q. In mode_specific, action1+Z changes incorrect→correct with probability.75 and preserves correct with probability.88; the other continuation uses.20 and.70. Public accuracy is.80. noisy_public changes only public accuracy to.60, a separately declared synthetic regime. Exact enumeration integrates latent Q; the Bayes public-history oracle never receives Q as a policy argument. Oracle parameters are used solely for qualification truth, never for fitted Q values.
