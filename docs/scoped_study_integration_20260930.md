## An informative finite-roster target

Condition on frozen development information, policies and the execution law, excluding realized evaluation random draws, seeds and outcomes, and a fixed held-out family census \(G\). Define a fixed within-family root aggregation or sampling law. For each family, prospectively assign the same number \(R\) of fresh whole-trajectory executions; initial answers are regenerated, not reused across repetitions. All locked strategies and roots within one family-repetition form one complete contrast vector \(D_{gr}\in[-1,1]^2\). Shared starts or branches are allowed inside that vector under the declared marginal laws. Families remain equally weighted.

The narrowly claimed target is

\[
\theta_j=\frac{1}{|G|R}\sum_{g\in G}\sum_{r=1}^{R}E[D_{grj}\mid\mathcal F].
\]

Under the unchanged law across repetitions this is the equal-family expected contrast on this fixed census. It does not describe a broad distribution of new task families. Changing root sampling, receiver, policies, endpoint or budget changes the target.

Assume all complete vectors are independent conditional on \(\mathcal F\); nonidentical family laws are allowed, while dependence within a vector is unrestricted. Independence requires a stable, restored execution process and fresh draws and is not proved by seed or ID strings. For either sign, \(X_{grj}=\max(\pm D_{grj},0)\in[0,1]\). Classical bounded-variable concentration gives

\[
\begin{aligned}
E[\exp(t\sum_{g,r}X_{grj})\mid\mathcal F]
&=\prod_{g,r}E[\exp(tX_{grj})\mid\mathcal F] &&\text{(conditional independence)}\\
&\le\prod_{g,r}\{1+(e^t-1)E[X_{grj}\mid\mathcal F]\} &&\text{(convexity)}\\
&\le\left[\frac1{|G|R}\sum_{g,r}\{1+(e^t-1)E[X_{grj}\mid\mathcal F]\}\right]^{|G|R} &&\text{(AM--GM)}\\
&=\left[1+(e^t-1)\frac1{|G|R}\sum_{g,r}E[X_{grj}\mid\mathcal F]\right]^{|G|R}.
\end{aligned}
\]

Chernoff optimization permits the existing outward-conservative sign-split KL arithmetic with \(n=|G|R\) independent **execution vectors** and the same eight-tail allocation for two contrasts. This is a classical argument, not new foundational theory; see [Hoeffding (1963)](https://www.cs.rpi.edu/academics/courses/spring06/random/hoefding.pdf). Valid pathwise missingness bounds retain every assigned vector and contain the complete-data interval. Undefined outcomes, corrupt observations and dependent vectors are not repaired by missingness bounds.

`experiments/prompt_choice/census_inference_v1.py` makes this an explicit new scope, reports actual family and assigned-vector counts separately, requires balanced full assignment, refuses duplicate initial-execution IDs, binds roster/law/policies/receiver/observer, and pins alpha and the strict five-point usefulness target. IDs can still be falsified or relabeled; the actual collector and raw evidence must establish fresh execution. No n, roster or run is selected by this source implementation.

The dependence warning is decisive: repeating the same Bernoulli draw rather than regenerating starts can yield zero coverage for this interval once R is large. Repetitions add execution precision, not independent task families, and must not be applied to the old ten-seed/checkpoint panel to upgrade its claim. The old family-level analysis and results remain untouched.
