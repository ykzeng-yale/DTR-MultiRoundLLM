# Bounded compute-node isolation capability check

ACT-02 requires a trustworthy broadly usable execution path; a frozen local literal sandbox exists, while native dependency execution and the auxiliary Docker route remain unresolved. Installed Bouchet bwrap/Apptainer commands do not prove isolation. Yale's container guide explicitly warns that normal containers expose home directories by default: https://docs.ycrc.yale.edu/clusters-at-yale/guides/containers/ . This NEW preflight checks a specific deny-by-default namespace construction; it does not rerun hardware calibration or any benchmark/model experiment.

Submit exactly one standard day CPU job, pi_fl426,1CPU/1GiB/5minutes, inner60second wall/CPU limit,1MiBfile cap,$0,no GPU. Source and plan frozen before submission; unique remote directory. No image download, package installation, network connection, receiver call, candidate/reference/benchmark execution or peer process action. Only a trusted harmless Python probe is executed under bwrap; if bwrap fails no unisolated fallback is permitted. Versions queried on compute node only. No privilege escalation, host security setting or daemon changes.

The child requests new user/mount/network/PID/etc namespaces with all capabilities dropped, empty environment, read-only /usr and runtime library mounts, new /proc,/dev,/tmp and empty/work. It receives only known canary path and namespace identifiers. Check host canary/home/project absence, distinct network/PID namespaces, cleared environment, writable private tmp, isolated working directory and absence of external IPv4 routes without contacting anything. Preserve stdout/stderr/exit and unchanged owner-created canary. Negative results are useful and must not trigger blind retries, relaxed isolation, installs or site-policy changes.

Pass is only a prerequisite, not adversarial proof or execution release. Seccomp/syscall restrictions, complete filesystem/inherited-descriptor attack review, network protocol coverage, descendant/process limits, dependency/image reproducibility and trusted observation transport still require qualification before any generated candidate could be considered. Existing prohibition on Bouchet candidate execution remains intact. If denied, record this route unavailable under the tested settings and advance local source-separated measurement; do not ask again to restart Docker.
