As an optimistic arithmetic ceiling only, if each of all 198 frame roots were one independent, equally weighted, complete family, its radius under that same rule would be `sqrt(2 log(80)/198) = 0.21038749`. The usable independent-family count is unknown and at most 198 within this listed frame; the actual radius under that fallback could be larger or undefined if sampling and independence fail. This is not a confidence interval for any current E12–E14 result. It does not rule out observing a large effect, nor does it rule out another prospectively justified procedure or a narrower finite-frame question. It does rule out meeting the **.05 radius planning target under this specified conservative fallback using only these 198 roots**, even under the most favorable family count.
