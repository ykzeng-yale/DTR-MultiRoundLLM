## Findings requiring precise assumptions

1. **Coverage must concern eligible, behavior-supported candidates.** Equation (13) restricts selection to `J(h,C)`, while the initially reviewed equations (17)–(20) wrote unrestricted slate maxima and near-optimal proposal events. If one high-value candidate has behavior probability zero, it can be present in the slate yet unavailable to the supported selector. For a one-stage example, let its value be 1 and all supported candidate values be 0. The unrestricted slate coverage loss would be zero, but the supported policy's regret is 1 even with exact Q. Thus equation (19) fails under that interpretation. Every maximum, greedy selection, critic-error domain, and proposal-coverage event must use the same eligible, supported set. Counting independent proposals before filters is valid only if the near-optimal event implies an eligible, selectable retained candidate. **Status: repaired and verified. Equations (17)–(20), their policy/error domains, and proof now consistently use the eligible supported set and a preservation condition.**

2. **Action-specific labels need action-specific support.** For equation (11) and Theorem 6, require positive true and supplied selection probability for the particular index `j`, even when the evaluation policy assigns that index zero probability. Support for evaluating a fixed policy alone does not ensure support for every alternative prompt contrast. Future target-continuation support is also needed after forcing that candidate. The Python `action_pseudo_outcome` already rejects an unsupported requested candidate. **Status: repaired and verified. The equation (11) introduction and Theorem 6 explicitly require both probabilities to be positive for each queried index, even when its target probability is zero.**

3. **Coverage-proof parameter range.** State `0 <= eta_t <= B_t`, with p a probability and K the positive number of proposals, or replace eta by its capped version when using the purported tighter expression `eta*(1-q)+B*q`, where `q=(1-p)^K`. Replacing the actual failure probability by an upper bound in this tighter expression requires `B-eta >= 0`. The looser displayed bound `eta+B*q` is valid for nonnegative eta without that additional restriction. Pure deduplication that preserves the maximum and counts the original independent draws does not itself change the inclusion event; independence cannot instead be asserted for an arbitrary post-filter unique-candidate count. **Status: repaired and verified. The corollary states the eta range, counts original draws, and distinguishes membership-preserving deduplication from filters that break independence or remove qualifying candidates.**

4. **Training reward convention should be explicit.** The supplied training recursion has no separate `R_t` term. It matches the implementation when terminal `U` contains the complete cost-adjusted return and all intermediate rewards are zero. If instead future implementations use per-step costs, both recursions must use `R_t+L_{t+1}` and the terminal target must exclude those costs. This is a documentation clarification, not an observed numerical mismatch in the delivered simulator. **Status: repaired by the integrating author and verified by rereading the training specification; it now explicitly states terminal total utility and `R_t=0`.**

## Checks supporting the remaining statements

- **Theorem 4:** reindexing the Q-error terms gives the displayed sign `(1-e/ehat)*(Qhat-Q)`, with previous cumulative weight ending at `t-1`. The true Bellman residual has conditional mean zero. This establishes stagewise mixed robustness for actual target-continuation Q functions; it does not establish correctness of fitted regressions on arbitrary downstream labels. Exact enumeration tests in the reference package cover the remainder and mixed-robustness identities.
- **Rate assumptions:** equation (7) correctly uses relative assignment error and a possibly training-dependent weighted measure. Lower bounds and domination are stated before converting to ordinary absolute propensity norms. Root-n linearity additionally assumes L2 convergence of the score and cross-fitting by independent roots. These are sufficient assumptions, not a proved neural rate theorem or uniform long-horizon guarantee.
- **Theorem 5 and natural-generator correction:** the fixed external target has zero pathwise derivative along logging-generator perturbations. A natural-generator target has derivative represented by the extra previous-weight term `Omega_(t-1)*(W_t-V_t)`. The observed-slate recursion contains this variability and must not inherit the known-generator efficiency claim without the appropriate model distinction.
- **Independent one-stage numerical check of that distinction:** take `C~Bernoulli(p)` at `p=.4`, behavior `P(J=1|C=c)=.2+.4c`, target `.7-.2c`, and outcome mean `.1+.3c+.4j`. Then `W(0)=.38`, `W(1)=.60`; the natural value derivative in p is `.22`. Complete enumeration over C, J, and binary outcome gives influence-score covariance with the generator score of `-1.39e-17` for the fixed target and `.22` for the natural target. This checks the correction in a finite example; it does not verify the entire semiparametric theorem formally.
- **Theorem 6:** conditional averaging gives the current product bias plus `(b_j/bhat_j)` times the downstream continuation bias. Local randomization correctness alone cannot eliminate arbitrary downstream bias. The action-specific Python labels use the same construction, with terminal total utility and a named target continuation.
- **Theorem 7:** telescoping baseline values under target-policy occupancy yields the displayed performance-difference identity. The simultaneous-error-event condition is essential for the lower bound and is correctly distinguished from ordinary pointwise intervals. The finite-class holdout bound requires a fixed class and independent bounded root scores; it cannot justify repeatedly adapting to the same holdout.
- **Theorem 8, after consistent support restrictions:** decomposition (18) follows by adding and subtracting the best eligible slate value along the learned policy's occupancy. The bound (19) separates unrestricted-versus-restricted optimal continuation from greedy error against the restricted optimal Q. A critic for an arbitrary baseline continuation cannot replace that restricted optimal critic.

## Limits of this review

The fixed-slate simulator does not test random-generator integration, a learned history/text encoder, nuisance convergence, simultaneous neural uncertainty, a trained free-form generator, hidden human confounding, or real LLM effectiveness. It tests a terminal-utility specialization with absorbing STOP and independent root clusters. The exact one-stage calculation above supplies a separate random-slate algebra check only. Literature priority and empirical assumptions were outside this bounded audit. No claim of full formal verification or complete submission readiness follows from this review.
